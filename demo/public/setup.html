Synthetic content only. Local HTTP is not safe for public deployment or personal accounts. On a LAN, all credentials travel in cleartext. Never share the owner credential with an agent.

Log in locally to claim and approve.

1. Owner login

Read %LOCALAPPDATA%\DisplayOS\owner-credential.txt privately on the Windows server computer. Other systems use .runtime/owner-credential.txt. An explicit runtime override changes this location. The service logs the path, never the credential. There is no account registration.

2. Claim one display

Copy the code and pairing session from the display you intend to own. Claiming never grants agent access.

3. Review agent requests

Agent labels are self-reported. Review the exact display ID, permissions, and lifetime. This is a local grant, not OAuth or a verified AI identity.
